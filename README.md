# DCD EK PWA

PWA pública de ElektroKabel para la Expo DCD.

## Privacidad
Este repositorio **no contiene la base privada de contactos**. Las fichas se importan localmente en el dispositivo y se almacenan en el navegador/PWA.

## Funciones
- Directorio local de contactos
- Buscador y filtros
- Scanner QR de gafetes
- Leads y notas locales
- Exportación / respaldo JSON y CSV
- Modo discreto
- Offline después de instalarse
